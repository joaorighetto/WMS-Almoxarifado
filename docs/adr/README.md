# Architecture Decision Records

Este diretório reúne os Architecture Decision Records (ADRs) do projeto:
registros de decisões arquiteturais importantes e difíceis de reverter, com
o contexto, a decisão tomada e as consequências.

Decisões triviais ou facilmente reversíveis não devem virar ADR.
